# Halcyon 0.7.5

- **Phone messages:** use KDE Connect conversations as a desktop widget, an Activity island entry, or both. Pair your phone with KDE Connect first. Message text stays hidden unless you enable it; this release has been exercised with sample conversations, not a paired phone.
- **Dark glass widgets:** a near-black, transparent style with a fine edge, subtle grain and a short shader glint on hover. It honors your chosen opacity; Readability help can add fill when needed. The effect respects reduced motion and keeps a native card fallback for software rendering.
- **Clocks:** five more faces—Stacked, Split, Words, Minimal and Numbers—plus four bundled typefaces, visual choices on the Clock page and a clearer view of where the clock sits behind the scene.
- **Calendars:** add CalDAV accounts, authenticated calendar links, local calendar files and folders, holiday feeds and calendars from system accounts. Choose the days shown, event colors, all-day events and location details. Provider requirements are explained in Settings and the calendar guide.
- **Easier to use:** clearer distinctions between looks, themes and styles; more useful search and error messages; recoverable first-run setup; and safer Arrange, Undo and day/night changes. Settings can shrink to 640 pixels wide.
- **Activity island:** return from Devices to the main activities, undo Clear all briefly, read longer notification previews and recover notification connections after interruption.
- **Fixes:** music covers can come from the player's own server and use WebP. Separate light/dark wallpapers, clock depth, icon overlays and weather effects keep their choices more reliably, and more settings save off the desktop's UI thread.
