# Halcyon 0.6.1

- **Usage reports go straight to Halcyon:** if you share usage data, the daily report now goes directly to Halcyon's own collector instead of through Google.
- **Which features are on:** the daily report also says which main features are switched on: the wallpaper effect, the Activity island, Penumbra, Islands, which widgets are shown, the audio visualizer, wallpaper depth, the theme style and automation. Only on or off and fixed names, never what's in your widgets. Details are in the [privacy notes](../PRIVACY.md). Turn it off with **Share usage data** under **App settings → Privacy**.
- **Public statistics:** totals from all reports are published at [halcyon-reports.profilaz3.workers.dev](https://halcyon-reports.profilaz3.workers.dev/). Only aggregates, and small groups are hidden.
