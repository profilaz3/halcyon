# 0.6.5 acceptance

This release adds Match the weather, the Clock stage, the scene covering the clock on your own wallpapers, a clearer Islands setup, the Changes history and the Time of day page, and lowers idle CPU and video memory use. Usage reports move to schema 7. The panel source and both panel patches are unchanged from 0.6.1, so the three published panel binaries were reused byte for byte and the startup policies stay the same. Of the companion helpers only `refresh.py` changed: turning Islands on after a reinstall now adopts a panel selector that Halcyon itself shipped.

## Distribution contract

The startup policies are unchanged: `cosmic-1.10-1.11-startup-v5` for Pop, `fedora43-cosmic-1.10-1.11-startup-v3` for Fedora 43 and `fedora44-cosmic-1.11-startup-v2` for Fedora 44, each still bound to the reused panel ELF. The policies of published 0.5.x releases stay accepted.

Reports from 0.6.5 go only to `halcyon-reports.profilaz3.workers.dev`, without following redirects, and use schema 7 under the existing **Share usage data** choice. The release check now requires the collector to answer schema 7 before release. [PRIVACY.md](../PRIVACY.md) lists every field.

## Scope

Native rendering used private nested compositors with software rendering. These checks do not qualify physical GPU and display combinations, full Fedora login sessions or enforcing SELinux. Reporting against the live collector was not exercised by this acceptance; the collector and client are covered by automated tests. No installed host package or desktop session was changed.
