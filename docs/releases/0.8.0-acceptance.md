# Halcyon 0.8.0 release verification

## Changes reviewed

The comparison starts at the published 0.7.8 tag. The release includes the widget, Activity island, Settings and command-line work in PRs #134 to #148, and the Outlook time zone fix in #133. PRs #142 to #148 overlapped in the Notes card, the saved widget fields and shared tests. They were merged in order, and each step on main was compile-checked before the next. PR #128 concerns the separately deployed public reports website. [Feature notes](0.8.0.md)

## Tests

- The full local Rust suite passed on the merged main tree: 2,451 tests passed, none failed and 38 are ignored by default. GitHub CI passed on the same merge and on the release commit.
- On the release commit, the release notes, What's new, search and navigation tests passed (53 tests), as did the controller and packaging Python tests and AppStream validation.

## Install and upgrade

| Target | Fresh installation | Upgrade from published 0.7.8 |
| --- | --- | --- |
| Pop!_OS 24.04 amd64 | APT installed the main DEB in a network-isolated filesystem overlay. Package ownership, all three executables and the package database passed verification. | APT upgraded the main and transitional Islands packages. User preferences, disabled update enrollment and the enabled Islands selection survived. The installed helper refreshed the selected generation. |
| Fedora 43 x86_64 | DNF installed the signed RPM from its signed repository. The application, dock applet and panel matched their target-specific hashes and `rpm -V` passed. | DNF upgraded the signed 0.7.8 package. The disabled repository, user files and the enabled Islands selection were preserved, and Islands could be turned off and on again. |
| Fedora 44 x86_64 | The same installation and payload checks passed with the Fedora 44 build. | The same upgrade and preservation checks passed with the Fedora 44 baseline. |

Both Fedora targets rejected a modified RPM, modified repository metadata and an unavailable repository.

## Behavior and source

- The packaged Settings window drew in a private COSMIC session on Pop!_OS and in nested COSMIC sessions on Fedora 43 and 44. The Islands panel and Penumbra checks passed at native and fractional scale on Pop!_OS and in each Fedora session. All fixture processes exited.
- Pinning Music from the Activity island with the keyboard saved its placement in the packaged app.
- Halcyon was built from locked, vendored source on Pop!_OS and on each Fedora target, with Rust 1.93.0. The Islands panel source has not changed since 0.7.6 and the magnifying dock source since 0.7.8, so their verified platform binaries are reused. Halcyon, the magnifying dock and the Islands panel each resolve offline with an empty Cargo home from the corresponding-source archive.

These checks used software rendering in isolated package managers and nested COSMIC sessions. Physical GPUs, full Fedora logins and enforcing SELinux sessions were outside their scope.
