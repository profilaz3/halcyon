# Halcyon 0.7.8 release verification

## Changes reviewed

The comparison starts at the published 0.7.6 tag. The candidate includes Markets, album lighting, Activity island pinning, and the ECB currency provider from PRs #123, #125 and #126. It also includes the desktop audit fixes in #124 and the appearance, widgets, dock and workspace work in #127. Their overlapping Markets, Settings and Activity island changes were reconciled together. PR #128 concerns the separately deployed public reports website. | Target | Fresh installation | Upgrade from published 0.7.6 |

Release packaging now requires the magnifying applet, its launcher and its license notices. Fedora provenance records the applet checksum alongside Halcyon and the panel. RPM license notices also install on systems configured to omit documentation. The native Islands panel for each target matches the binary shipped in 0.7.6.

## Behavior and source

- The public stock quote and history request and the ECB reference-rate request succeeded without credentials. The widget gallery uses the observed November 19 rates. Native tests cover compact and wide layouts, glass rendering, both Weather layouts, the glass library and workspace editor.
- The packaged app received a synthetic MPRIS track in a nested COSMIC session. Pinning Music from the Activity island with the keyboard saved its placement. The packaged dock applet kept four independently clickable launchers and respected reduced motion. Its process used zero measurable CPU time during a settled 60-second software-rendered sample.
- Native image review exposed a Folder thumbnail drawing into the filename and header. The corrected widget fits both landscape and portrait thumbnails inside the preview area. A pixel regression test exercises both orientations.
- Settings search and the in-app release note reach Dock magnification even when the required applet is missing. The row describes how to enable it for the selected dock.
- The Fedora application and dock binaries were built from locked, vendored source on their respective targets. Halcyon, the magnifying dock and the Islands panel each resolve offline with an empty Cargo home. The corresponding-source archive carries all three patched trees and their dependencies.

## Final packages

The final Pop!_OS DEB and both Fedora RPMs include the Crystal shader reviewed in [PR #130](https://github.com/profilaz3/halcyon/pull/130). Its native regression checks the color and position of a wallpaper stripe at 100%, 150% and 200% display scaling. The local application suite passed 2,403 tests with 38 ignored. [Native Crystal capture](../screenshots/desktop-customization/crystal-feather.webp)

- On Pop!_OS, APT installed the exact release packages both fresh and over 0.7.6. The upgrade preserved preferences, disabled update enrollment and the selected Islands panel. The packaged Settings window drew in a private COSMIC session. Panel and Penumbra checks passed at native and fractional scale, and all fixture processes exited.
- On Fedora 43 and 44, DNF installed, upgraded and reinstalled the signed RPMs from their signed repositories. Each upgrade preserved the disabled repository, user data and enabled Islands selection. Both packaged Settings windows and panels ran in nested COSMIC sessions. Signature tests detected modified RPMs and repository metadata.
- Halcyon, the dock applet and the Islands panel have separate locked dependency trees. The corresponding-source tarball stores identical files as hard links. Extracting it restores each tree for its own offline Cargo build.

The release record binds the DEB, panel, helpers and validation archive to their exact hashes. The validation archive also identifies each signed RPM, its three executable payloads and the platform-specific test results. These checks used software rendering in nested COSMIC sessions. Physical GPUs, full Fedora logins and enforcing SELinux sessions were outside their scope.
