# Halcyon 0.7.8 release candidate review

## Changes reviewed

The comparison starts at the published 0.7.6 tag. The candidate includes Markets, album lighting, Activity island pinning, and the ECB currency provider from PRs #123, #125 and #126. It also includes the desktop audit fixes in #124 and the appearance, widgets, dock and workspace work in #127. Their overlapping Markets, Settings and Activity island changes were reconciled together. PR #128 concerns the separately deployed public reports website. RPM license notices also install on systems configured to omit documentation. The native Islands panel for each target matches the binary shipped in 0.7.6.

## Behavior and source

- The public stock quote and history request and the ECB reference-rate request succeeded without credentials. The widget gallery uses the observed November 19 rates. Native tests cover compact and wide layouts, glass rendering, both Weather layouts, the glass library and workspace editor.
- The packaged app received a synthetic MPRIS track in a nested COSMIC session. Pinning Music from the Activity island with the keyboard saved its placement. The packaged dock applet kept four independently clickable launchers and respected reduced motion. Its process used zero measurable CPU time during a settled 60-second software-rendered sample.
- Native image review exposed a Folder thumbnail drawing into the filename and header. The corrected widget fits both landscape and portrait thumbnails inside the preview area. A pixel regression test exercises both orientations.
- Settings search and the in-app release note reach Dock magnification even when the required applet is missing. The row describes how to enable it for the selected dock.
- The Fedora application and dock binaries were built from locked, vendored source on their respective targets. Halcyon, the magnifying dock and the Islands panel each resolve offline with an empty Cargo home. The corresponding-source archive carries all three patched trees and their dependencies.

## Before publication

These are local candidate packages. The Fedora RPMs are unsigned. Production signing changes their checksums. Final publication requires the reviewed commit and CI results, the signed packages and repository metadata, and the final checksums and approval bound to those bytes. The native interaction samples used a nested software-rendered COSMIC session on Pop!_OS. Physical GPU, full Fedora login and enforcing SELinux sessions were outside these runs.
