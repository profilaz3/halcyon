## Distribution contract

Fedora policies bind a specific Fedora release, architecture and native ELF. The historical Fedora 43 policy remains unchanged. The new Fedora 43 policy supports COSMIC 1.10 and 1.11; Fedora 44 supports 1.11. Package eligibility still requires the actual interface probe and owned runtime readiness at startup.

The signed version-2 RPM review requires both Fedora targets. Package downloads and DNF payloads must match exactly. APT and both DNF repositories deploy together; retained version-1 reviews keep their original Fedora 43-only contract.

## Scope

Native rendering used private nested compositors and software rendering. These checks do not qualify physical GPU/display combinations, full Fedora login sessions or enforcing SELinux. No installed host package or desktop session was changed. The broader application regression suite remains part of release CI.
