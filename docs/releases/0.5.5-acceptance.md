# Halcyon 0.5.5 package verification

Reviewed on 2026-10-31. The DEB and Fedora 43 x86-64 RPM each contain Halcyon
and the shared Islands/Penumbra host. The native executables are built for their
respective distributions; both use the same pinned panel sources and patches.

## Completed checks

- 1,452 application Rust cases passed: 1,450 in the full release-profile run,
  followed by successful reruns of two corrected test fixtures. The corrections
  update privacy copy and expose Vulkan drivers to the isolated GPU test.
  The 22 explicit worker/platform exclusions remain separate.
- The 12 Islands core tests, 202 companion tests, 82 controller/helper tests,
  66 collector tests, packaging/enrollment and release-gate suites passed.
- All four wallpaper effects animated in a private COSMIC session. Lock, sleep,
  battery, occlusion, disable and service-loss checks stopped rendering;
  resumption, picture replacement and dock popup input worked.
- Circular Music styles and the spectrum passed native rendering, custom geometry,
  opacity, behind-dock input and playback-pause cleanup checks.
- The packaged Debian panel passed Standard, Together and Separate layouts on
  all four edges. Additional Debian and Fedora checks passed at 150% scaling
  with auto-hide. Disabling Penumbra left no residual gradient or changed Islands
  preferences. All fixture-owned processes were reaped.
- GPU Settings controls were rendered and inspected at 820×600 and 1280×800.
  Fedora passed 19 Updates tests plus the two platform-specific installed identity
  and RPM ordering tests. Its update views were captured at both supported sizes.
  Debian comparison fixtures use dpkg installed inside the disposable Fedora
  test container; the Fedora application uses RPM for its installed package.
- Real APT/dpkg completed fresh installation and upgrade from 0.5.0 in isolated
  namespaces. Real DNF completed signed fresh installation, reinstall and upgrade
  in the Fedora container. Preferences, Notes, Islands selection and disabled
  update sources were preserved. Fresh installation leaves Islands disabled.
- The RPM signature and signed repository metadata verified with the official
  archive key. Tampered package bytes, modified metadata and an unavailable
  repository were rejected. The download and repository use identical RPM bytes.
- Both source dependency closures resolve offline with empty Cargo homes. The
  source archive includes both native patches, the vendored recurrence correction,
  locked dependencies and license notices.
