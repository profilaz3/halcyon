# 0.7.5 acceptance

This release adds KDE Connect conversations as a widget or Activity island entry, Dark glass widgets, more clock faces and calendar sources, and the navigation and recovery improvements since 0.7.0. The Islands panel source, patches, binaries and startup policies are unchanged from 0.7.0. The three panel executables are reused byte for byte.

## Distribution and scope

The collector's live health response confirms usage schema 8. Dark glass uses the existing glass reporting category; message bodies and conversation details are not usage-report fields.

Native checks use software rendering and isolated sessions. They do not qualify physical GPU/display combinations, full Fedora login sessions, enforcing SELinux or COSMIC 1.10. Messages were tested with sample data, not a paired phone; no live calendar-provider acceptance is claimed. The release checks did not install packages into or modify the host desktop session.
