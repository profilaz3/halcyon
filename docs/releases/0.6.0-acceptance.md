# 0.6.0 acceptance

This release adds the Activity island (beta), rain, snow and fog setups, lower opacity floors and a rearranged Settings app. The pinned panel patch changed: keyboard focus now follows the applet popup that owns it, so Tab and Escape keep working after a popup takes a native grab. All three panel binaries were rebuilt from the same pinned upstream source.

## Distribution contract

The new startup policies are `cosmic-1.10-1.11-startup-v5` for Pop, `fedora43-cosmic-1.10-1.11-startup-v3` for Fedora 43 and `fedora44-cosmic-1.11-startup-v2` for Fedora 44. Each binds the new patch and a specific panel ELF. The policies of published 0.5.x releases stay accepted, unchanged, so a bundle staged by an installed 0.5.x package can still be read while the upgrade replaces it. An earlier candidate of this release dropped them, and upgrades with Islands enabled then reported "Compatibility update needed". The upgrade checks now enable Islands first and fail on that state.

The Islands core keeps its internal opacity floor; Halcyon now clamps dock and panel opacity itself, so they can be up to 55% see-through, and widgets up to 90%. Two COSMIC panel configuration crates are now direct dependencies. Their workspace declares GPL-3.0-only, and the license bundle records that.

## Scope

Native rendering used private nested compositors with software rendering. These checks do not qualify physical GPU and display combinations, full Fedora login sessions or enforcing SELinux. The Activity island is a beta and was not validated on a physical session: music, meetings, notifications, camera and microphone indicators were exercised by automated tests only. No installed host package or desktop session was changed.
