# 0.7.0 acceptance

This release adds looks you can take part by part and the Look studio, Rainy Lake and Deep Purple, icon packs and app icon shapes, the Edge menu page, Settings Home, Arrange over the real desktop, rain on fogged glass with the clock behind it, the grouped Activity island with live activities and a file shelf, and device batteries in the island and a Devices widget. Usage reports move to schema 8. The panel source and both panel patches are unchanged from 0.6.5, so the three published panel binaries were reused byte for byte and the startup policies stay the same. Of the companion helpers `panel_launcher.py` and `selector.py` changed: the Islands panel helper now waits on the panel's process handle instead of waking every 20 ms. The Islands autostart entry also stays quiet once the Islands files are removed.

The license expression is now `GPL-3.0-or-later AND GPL-3.0-only`, because the rain glass shader `src/rain/glass.wgsl` adapts code from Cosmic Forge under GPL-3.0-only. Halcyon's own source stays GPL-3.0-or-later; the Debian copyright file, the RPM header and THIRD_PARTY.md say so.

## Distribution contract

The startup policies are unchanged: `cosmic-1.10-1.11-startup-v5` for Pop, `fedora43-cosmic-1.10-1.11-startup-v3` for Fedora 43 and `fedora44-cosmic-1.11-startup-v2` for Fedora 44, each still bound to the reused panel ELF. The policies of published 0.5.x releases stay accepted.

Reports from 0.7.0 go only to `halcyon-reports.profilaz3.workers.dev`, without following redirects, and use schema 8 under the existing **Share usage data** choice. Schema 8 adds the Devices widget and page to the names a report can carry. The collector accepting schema 8 is live as version 53dc9f88; it answers schema 8 and still accepts schema 7 from 0.6.5. The release check requires the collector to answer schema 8 before release. [PRIVACY.md](../PRIVACY.md) lists every field.

## Scope

Native rendering used private nested compositors with software rendering. These checks do not qualify physical GPU and display combinations, full Fedora login sessions or enforcing SELinux. Reporting against the live collector was checked only through its health answer; the collector and client are covered by automated tests. No installed host package or desktop session was changed.
