## Selected graphic hero

[hero-graphic.png](hero-graphic.png) uses the Halcyon wordmark and icon with an
abstract wing composition, grouped Islands, System monitor, regular Music and
a Calendar agenda with sample events. The graphic is an illustration; it does
not depict an additional app screen or bundled wallpaper.

## Additional themed hero candidates

These alternatives use a compact cluster of panel Islands, System monitor and
regular rectangular Music widgets. They are documentation illustrations, not
bundled setups or evidence of a live account connection.

| File | Theme |
| --- | --- |
| [hero-boreal.png](hero-boreal.png) | Forest green and mint; aurora over a mountain fjord |
| [hero-ember.png](hero-ember.png) | Copper and aubergine; canyon sunset with an analog Clock |
| [hero-nocturne.png](hero-nocturne.png) | Indigo and lavender; riverside city and connected Calendar with fictional events |

The Calendar reference is a native fixture capture. Event titles, times and music
metadata are sample data. All three keep the center of the wallpaper open and
group the panel islands together at the top.

Exact generation prompts, input references and SHA-256 hashes are in
[prompts.json](prompts.json). Native Halcyon captures supplied the layout and widget
references. The effect artwork was generated from text. No personal data or
external album artwork was supplied. Sample music metadata is fictional.
The dock/panel and scheduling compositions were also generated from text.
The `references/` directory retains native and intermediate generated inputs
needed for the recorded prompts; other input captures already exist in the repository.

Widget, bar and audio images focus on the components, without desktop wallpaper
or scenery behind them. Their shared presentation background is dark charcoal.
Earlier pale-background component drafts remain as edit inputs only. Full desktop compositions are reserved for the hero, appearance
and setups. Earlier full-desktop drafts (`widget-customization.png`,
`dock-panel-layouts.png`, `audio-visualizers.png`) remain as source history and
are no longer embedded in the README.

The app selects one wallpaper effect and one circular Music style at a time.
The illustrations compare alternatives; they do not imply multiple simultaneous
Music widgets or exact scene-aware weather rendering. New illustrated landscapes
are documentation artwork, not additions to the app's bundled wallpaper library.

For actual output and controls, see the [native captures](../../screenshots/055/README.md).
Original generated files were copied into this directory without alteration.
